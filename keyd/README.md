# keyd config

System-level key remapping for one specific USB keyboard (a combo
keyboard+trackpad device), scoped so it doesn't touch the trackpad or any
other keyboard on the machine. This is Linux's rough equivalent of
Karabiner-Elements (see the `karabiner/` package for the macOS side) — a
daemon that remaps at the kernel input layer, below any window manager or app.

Not a stow package. `/etc/keyd/` is root-owned and outside `$HOME`, so this
is plain tracked config plus an install script, not a symlink.

## What it does

On the matched keyboard only:
- Swaps Esc and Tab
- Swaps Caps Lock and Left Ctrl
- Home row mods: hold A/S/D/F for Shift/Alt/Super/Ctrl (mirrored on the right
  as ;/L/K/J). Tap normally to type the letter. `overload_tap_timeout = 200`
  and the `150, 200` args to `lettermod()` control how long a hold needs to
  be before it counts as a modifier instead of a keypress — see
  `man keyd.conf` (`lettermod` / lookup `overloadt2`) if these need tuning.

## Setting up on a (new) machine

1. Plug in the keyboard.
2. Run `./install.sh` — installs `keyd`, enables the service, copies this
   config into place.
3. **Re-derive the device id.** The `[ids]` line in `usb-keyboard.conf`
   (currently `1c4f:007f:5bcae51d`) is generated by keyd from this specific
   USB port's physical path — it will NOT match on a different machine, or
   even the same keyboard in a different port on this machine. To find the
   right id:
   ```
   journalctl -u keyd --since "1 minute ago" --no-pager
   ```
   after a `sudo keyd reload`, and look for the `DEVICE: match`/`ignoring`
   lines. Find the line naming your keyboard's actual key-emitting interface
   (not its "Mouse"/"Touchpad"/"Consumer Control" siblings — those share the
   same vendor:product but are separate ids and should stay `ignoring`).
   Update `[ids]` in `usb-keyboard.conf` with that id, then
   `sudo keyd reload` again and confirm via the journal that only the
   correct interface shows `match`.
4. Test: touchpad/mouse (if the device has one) should behave normally, and
   the remaps above should work only on this keyboard.
